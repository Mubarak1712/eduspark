# EduSpark — Smart School Management Platform
Modern AI-Powered School Management SaaS Website built using React, Vite, Tailwind CSS, and TypeScript.
---
## Features
* Responsive SaaS UI
* Multi-page website
* Home Page
* About Page
* Contact Page
* Sticky Navbar
* Testimonials Section
* FAQ Section
* Statistics Dashboard
* Professional Footer
* Smooth Animations
* Mobile Responsive
* Supabase Integration
---
## Tech Stack
* React
* Vite
* TypeScript
* Tailwind CSS
* React Router
* Framer Motion
* Supabase
---
## Installation
Clone repository:
git clone YOUR_GITHUB_REPOSITORY_LINK
Move into project:
cd project

Install dependencies:
npm install

Run locally:
npm run dev

Open in browser:
http://localhost:5173
